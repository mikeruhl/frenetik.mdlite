## ADDED Requirements

### Requirement: Skill explains relative links to supporting files

The decision skill SHALL tell agents that relative links from the decision document to sibling markdown files open
in a new mdlite window after the user confirms, so supporting detail can live in linked files.

#### Scenario: Supporting detail guidance

- **WHEN** an agent reads the skill's authoring guidance
- **THEN** it finds a line explaining that relative links to sibling markdown files open after user confirmation
